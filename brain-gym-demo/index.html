Not a class. Not a tool library.

A gym model for practical skills.

You don't join a normal gym because you want one lecture about treadmills. You join because the equipment is there, the space works, and you can keep getting better. Brain Gym applies the same idea to making.

Questions people ask

Yes, beginners belong here.

Do I need experience?

No. The whole point is to create a place where competence can start from zero and grow through practice.

Is this a makerspace?

Sort of. The emphasis is less on access to gadgets and more on learning durable, transferable practical skills.

Can I work on my own projects?

That's the goal. Orientations establish what equipment you can use safely; then you build increasingly independently.

Is equipment maintained?

Yes. Reliable, sharp, calibrated, ready-to-use tools are part of the core value proposition.
